Build a Plugin

SweetVibe plugins are ordinary Python files. Put a .py file in the plugins/ folder beside main.py or the installed executable. The player loads it at startup and calls setup(player) when that function exists.

1. Create the file

Create plugins/my_plugin.py. Keep plugin code self-contained and use the player object passed to setup.

2. Register hooks

Append functions to player.plugin_hooks. Return True from on_command, on_key, or on_play_request when your plugin handled the event.

Available hooks

  • on_command(cmd, raw_text) handles command-bar commands.
  • on_key(key_str, action) handles keyboard input.
  • on_play_request(item) can replace normal playback.
  • on_play(filepath) runs when a local track starts.
  • on_stop() runs when playback stops.
  • on_draw(screen) draws on top of the player interface.
  • on_tick() runs once per player frame.
from asciimatics.screen import Screen

def custom_command(cmd, raw_text):
    if cmd == ":hello":
        player.add_log("Hello from my plugin!")
        return True
    return False

def custom_draw(screen):
    screen.print_at(" Plugin active ", 2, 0,
                    Screen.COLOUR_CYAN, Screen.A_BOLD)

def setup(the_player):
    global player
    player = the_player
    player.plugin_hooks["on_command"].append(custom_command)
    player.plugin_hooks["on_draw"].append(custom_draw)

Online tracks

For custom online items, add a tuple such as ("online", name, url, duration) to the playlist and handle it with on_play_request. Return True after starting your download or stream.

Included plugins

The packaged application keeps plugin files as Python files in plugins/. The built-in online plugin provides :yt, :sc, playlist commands, caching, and yt-dlp downloads.
