SweetVibe
Docs GitHub

SweetVibe is a fast, keyboard-driven music player for the terminal, with a native audio engine, a live audio-reactive spectrum and YouTube discovery — all in Python, with no external binaries.

SweetVibe — a terminal music player for Windows and Python

Download Documentation

Features

Everything ships in one executable. No FFmpeg, no bundled binaries.

Native Audio Engine

Low-latency playback through just_playback. Decodes mp3, ogg, opus, wav and flac.

Live Spectrum

Automatic, reactive and script-driven visualizer modes with falling peak caps.

YouTube Discovery

Search and download straight from the command bar, with caching and playlists.

Smart Library

Browse the bundled songs/ folder or scan the whole PC. Full CJK support.

Remappable Keys

An in-app editor writes your bindings to plain text. Bind multiple keys or reset.

Five Plugins

Online, lyrics, album art, a dancing girl and a dancing cat. All work fully offline.

Default Controls

Every one of these is rebindable in :settings.
