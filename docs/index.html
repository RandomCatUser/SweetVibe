SweetVibe is a music player for the terminal, built in Python with a native audio engine,
         a live audio-reactive spectrum and YouTube discovery. One executable, nothing bundled alongside it.

      

        Documentation
      

    


    
SweetVibe — a music player for the terminal

  







  

    

      
What it does

      
Everything below ships inside the one installer.

    


    

      

        
Local library

        
Browse the bundled songs/ folder, or scan every drive on the machine. CJK titles render correctly.

      

      

        
Live spectrum

        
Automatic, reactive and script modes, with falling peak caps.

      

      

        
YouTube

        
Search and download from the command bar. Fetched tracks are cached and replay instantly.

      

      

        
Playlists

        
Save the queue by name, load it back later, shuffle and repeat.

      

      

        
Rebindable keys

        
An in-app editor writes your bindings to a plain-text file you can also edit by hand.

      

      

        
Easter eggs

        
Five bundled plugins, all offline: a dancing girl, a dancing cat, lyrics and album art.
